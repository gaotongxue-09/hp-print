## 1. 数据安全与隐私

**核心原则：数据默认留在本地，不上传云端。**

- **本地存储**：打印任务、扫描件、多页文档、纸张模板配置等数据仅存储在设备本地，应用不设云端同步，不出境、不上传。
- **敏感数据加密**：涉及证件照、扫描件等敏感文件时，建议使用 Android Keystore 派生的密钥进行落盘加密，密钥不出安全硬件（TEE / StrongBox）。
- **临时数据清理**：打印/扫描产生的临时文件在使用结束后自动清理，避免残留副本。
- **OCR 本地化**：文字识别使用 ML Kit 中文模型，在设备端完成，识别文本不经过网络。
- **日志脱敏**：日志中不记录文档内容、证件号、路径等敏感信息，只记录必要的状态与错误码。

## 2. 权限最小化

**原则：只申请完成任务所必需的最小权限，并在使用时动态申请、说明用途。**

| 权限 | 用途 | 说明 |
|------|------|------|
| 相机 | 扫描、证件拍摄 | 仅在进入取景页时申请 |
| 存储（SAF / 分区存储） | 读取/导出文档、图片、PDF | 只访问用户主动选择的文件，不申请全局存储权限 |
| 网络 | 打印机通信、检查更新 | 仅访问打印机与更新服务器 |
| 位置（可选，用于 Wi-Fi 发现） | 局域网打印机发现 | 需在系统设置中显式授权 |

**明确不申请的权限**：通讯录、短信、通话记录、麦克风、后台定位等与本应用功能无关的权限。

## 3. 网络与通信安全

- **IPP / IPPS**：打印任务支持 IPP over TLS（`ipps://`）加密传输，优先使用加密连接，避免打印内容在局域网内明文泄露。
- **SNMP / EWS**：仅用于**只读**查询打印机状态与耗材信息，不传输、不回传任何用户文档。
- **打印机扫描协议**：扫描数据通过受控连接返回，扫描结果仅落盘本地。
- **检查更新**：更新请求与下载均走 HTTPS，并对下载包做完整性校验（签名/哈希）后再安装。
- **网络文章打印**：使用 Jsoup 提取正文时过滤脚本、跟踪代码与恶意跳转，仅保留正文内容重排打印。
- **证书校验**：对 HTTPS 请求执行标准的证书链与主机名校验，不信任自签名证书，不绕过校验。

## 4. 敏感数据处理（证件类）

证件照排版、身份证复印、证件复印（身份证 / 银行卡 / 护照 / 行驶证 / 驾驶证 / 居住证 / 户口本 / 营业执照）属于**高度敏感个人信息**，处理规则如下：

- **仅本地处理**：证件图片与识别结果只在设备端使用，用于排版与打印，不联网传输、不上传任何服务。
- **用完即清**：身份证正反面等证件图片在完成打印后提供「一键清除」入口，不保留副本；不写入应用缓存目录之外的位置。
- **用途透明**：首次使用证件功能时明确告知用途与数据留存范围。
- **导出可控**：导出 PDF / 图片由用户主动触发，导出的文件归用户所有。

## 5. 应用安全

- **代码混淆**：发布构建启用 R8 / ProGuard 混淆，压缩并隐藏实现细节。
- **防二次打包**：对发布包做完整性校验（签名校验），检测被篡改/重签名的安装包并拒绝运行或提示风险。
- **不硬编码敏感信息**：禁止在源码、配置文件、资源中硬编码密钥、密码、令牌等（见第 6 节）。
- **加固（可选）**：如需要可叠加第三方加固，但需评估与开源协议及系统兼容性的影响。

## 6. 签名与发布安全

> 本节为本次安全筛查的重点整改项。

- **签名密钥离线保管**：APK 签名密钥（`.jks` / `.keystore`）应离线保存，**不进入 Git 仓库、不随源码或安装包分发**。
- **密码不落库**：密钥密码、别名密码**禁止写入** `gradle.properties` 或任何会被提交到仓库的文件；改用环境变量、CI Secret 或本地未跟踪的 `sign.example.properties` 引用。
- **密钥轮换**：一旦怀疑密钥或密码泄露，立即更换密钥并通知用户升级（APK 签名密钥更换会导致无法覆盖安装，需妥善规划）。
- **发布流程**：签名仅在受控环境完成，CI 构建产物（如 KernelSU 的 ksud / lkm）与 App 产物分离管理。
- **已知整改**：已从仓库移除 `manager/key.jks` 与 `manager/gradle.properties` 中的明文密码，并在 `.gitignore` 中追加 `/manager/key.jks` 等规则。**仍建议尽快更换现有签名密钥密码。**

## 7. 供应链安全

- **依赖来源可信**：第三方依赖来自官方仓库或可信镜像，锁定版本，定期检查安全通告（CVE）。
- **第三方组件审查**：对引入的扫描/渲染引擎（如 ScanLite 等）进行来源与协议审查，避免引入未授权或含后门的专有二进制。
- **开源许可合规**：遵循所使用开源项目的许可证要求，在「关于」页列出引用项目。
- **产物可信**：不将专有二进制（如 HP 打印机私有 `.so` / `.tflite`）、逆向脚本等未经授权的文件纳入仓库分发。

## 8. 安全检查清单

发布前逐项核对：

- [ ] 签名密钥已离线保存，未进入仓库
- [ ] `gradle.properties` / 配置文件中无明文密码、令牌
- [ ] `.gitignore` 覆盖密钥、`local.properties`、构建产物、个人目录
- [ ] 权限按最小化原则声明，无无关权限
- [ ] 打印 / 扫描默认走加密通道（IPPS / HTTPS）
- [ ] 证件类敏感数据仅本地处理，提供清除入口
- [ ] OCR 在本地执行，识别文本不上传
- [ ] 发布包已开启混淆与签名校验
- [ ] 第三方依赖已审查并锁定版本
- [ ] 仓库中无专有二进制、逆向脚本、个人路径残留
