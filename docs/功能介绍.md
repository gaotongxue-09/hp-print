# HP Print 功能总览

> 本文件完整描述了 HP Print 的全部功能模块，作为产品规划与功能清单使用。

---

## 1. 首页（仪表盘）

- **默认打印机卡片**：状态（在线 / 离线 / 空闲 / 忙碌 / 错误）、一键刷新、重命名
- **引导卡片**：未添加打印机时展示，点击跳转到添加流程
- **快捷操作**：打印文档、打印照片、网页打印、扫描
- **最近活动**：展示最近的打印任务及其状态
- **耗材（墨水量）**：黑色 / 青色 / 品红 / 黄色 / 照片黑，低于阈值标「低」

---

## 2. 打印

- **打印任务页**：进行中任务 + 历史记录；历史支持「按日期 / 按格式（图片 / 文本 / 网页）」分类
- **文件选择**：PDF、Word、TXT、HTML、图片；引擎另外支持 OFD、PPTX、XLSX 渲染
- **打印设置**：
  - 打印机选择
  - 份数
  - 彩色 / 黑白
  - 纸张尺寸
  - 双面（关闭 / 长边翻转 / 短边翻转 / 手动双面）
  - 打印质量（草稿 / 标准 / 高质量）
  - 方向（纵向 / 横向）
  - 打印范围（全部 / 自定义起止页）
- **手动双面**：说明弹窗 → 打印正面 → 通知 / 确认页提示翻面 → 继续打印背面
- **打印预览**：发送前逐页查看
- **照片打印**：原尺寸、3×5、4×6、5×7、一寸 / 小一寸 / 大一寸 / 二寸 / 小二寸、身份证尺寸
- **电子发票打印**：PDF / OFD
- **网络文章打印**：输入网址，用 Jsoup 提取正文后重新排版打印

---

## 3. 网页打印

- 直接输入网址打印整页网页
- 网络文章模式：只抓正文、去广告排版后打印

---

## 4. 扫描

- **入口**：从相册选择、调用打印机扫描仪、手机相机文档扫描、扫描历史、扫描参数设置
- **相机扫描（自研取景页）**：单页 / 多页、超清 / 高清 / 标清三档、自动 / 手动裁边、闪光灯、相册导入、实时边缘检测与黄色取景框
- **拍后处理**：四角微调、旋转 90°、重置、重拍 / 确认
- **多页文档页**：添加页面、单页裁切、删除页条、滤镜（原图 / 增强 / 灰度 / 黑白 / 去阴影）、重命名、删除文档
- **导出**：导出 PDF、保存为图片、直接打印文档
- **文字识别（OCR，中文模型）**：逐页识别、复制、分享、导出 TXT、重新识别
- **扫描参数**：分辨率、色彩模式（彩色 / 灰度 / 黑白）、单面 / 双面、输出格式
- **扫描历史**：全部 / 文档扫描 / 图片扫描 / 身份证 分类筛选
- **打印机扫描件预览与保存**

---

## 5. 证件类工具

- **证件打印（IdPrint）**：三种来源（打印机扫描仪 / 手机摄像头 / 相册），自动检测边缘并透视矫正；证件类型下拉选择（身份证、银行卡、护照、行驶证、驾驶证副页、居住证、户口本、营业执照）；按实物 1:1 排版到 A4 预览后打印
- **身份证复印（IdCardCopy）**：正面 / 反面分步扫描或拍摄，带玻璃板摆放引导，调整（旋转 / 重置 / 翻转 180° / 边框），上下或左右排版，保存到扫描文档或导出 PDF
- **证件照排版（IdPhoto）**：相册选照，选证件尺寸 + 相纸尺寸（5 寸 / 6 寸 / 7 寸 / A4）+ 背景色（白 / 蓝 / 红 / 无），生成多张排版预览后打印

---

## 6. 纸张模板

- **模板库**：双列缩略图 + 搜索
- **内置类别**：基础纸、书法纸、中文格纸、教育用纸、五线谱 / 音乐纸、笔记纸、计划表、特殊纸、其他
- **参数调整**：纸张尺寸、方向、背景图案、纸张颜色、线条颜色、线间距 / 线宽、边距、页数、水印文字、Logo（文字或上传商标图）
- **全屏预览**：双指缩放、翻页
- **输出**：直接打印 / 保存为 PDF

---

## 7. 打印机管理

- 网络发现打印机 + 手动添加（IP + 端口）
- 检查连接（可达 / 不可达）、设为默认、重命名、移除
- **打印机详情**：型号、连接方式、在线状态、墨水量
- **状态轮询监控**（StatusMonitor）
- **打印机扫描仪调用**（分辨率 / 色彩 / 单双面 / 格式）

---

## 8. 设置与个性化

- **界面风格双形态**：Miuix / Material 一键切换
- **主题配色**（ColorPalette）
- 打印机管理入口
- **检查更新**（可开关自动检查）与更新安装
- **关于**：版本、开发者、引用项目、GitHub / 酷安链接
- **首次启动引导页**（欢迎 → 界面风格 / 主题 → 完成）

---

## 9. 底层能力

- **打印协议**：IPP 打印、打印机状态 / 耗材读取（SNMP / EWS）、打印机扫描协议
- **文档渲染引擎**：PDF、DOCX、PPTX、XLSX、OFD、HTML、TXT、图片
- **扫描引擎**：原生检测库 + ML Kit 中文 OCR + 透视变换 / 裁边 / 滤镜
- **本地存储**：打印任务、扫描件、多页文档、纸张模板配置
